# OrbitIQ Labs

**Intelligence in orbit around discovery.**

Official website for OrbitIQ Labs - Advancing the frontier of autonomous discovery, agentic intelligence, and scientific literacy.

## 🌐 Live Site

- **Production**: https://www.orbitiqlabs.space
- **Status**: 🚀 Ready for deployment

## 🏗️ Tech Stack

- **Framework**: TanStack Start (React)
- **Styling**: Tailwind CSS 4.x
- **Build Tool**: Vite
- **Deployment**: Vercel (recommended)
- **Language**: TypeScript

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
